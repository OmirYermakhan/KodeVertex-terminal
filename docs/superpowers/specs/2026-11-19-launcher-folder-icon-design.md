# Быстрые входы: папка проекта и своя картинка

## Зачем
Входы в полосе слева сейчас — только сохранённые команды (обычно ssh) со значком из 12 готовых.
Владелец хочет держать там проекты: клик — вкладка сразу в папке проекта (claude запускает сам),
и у каждого проекта своя картинка с Мака, чтобы не путать их.

## Цели
- Папка входа: выбирается диалогом macOS; вкладка входа всегда открывается в ней.
- Команда необязательна: пустая — вкладка просто открывается в папке, ничего не запускается.
- Своя картинка (png/jpg/gif/webp — то, что уже читает код вложений; svg декодер не умеет) вместо готового значка; сброс — назад к готовым.

## Не цели
- Автозапуск claude, открытие конкретного файла, изменение кнопки «+».

## Подходы (выбран А)
- **А — картинка уменьшается до 64×64 PNG и хранится data-URL прямо в настройках.** ~5–10 КБ
  на вход, не ломается при переносе исходника, никаких файлов и чистки. Выбран.
- Б — копия в папке приложения + путь: надо следить за файлами и удалять копии. Отклонён.
- В — путь к исходнику: ломается при переносе файла. Отклонён.

## Дизайн
- `Launcher` получает `cwd?: string` и `image?: string` (data:image/png;base64, ≤ ~64 КБ).
  `normalizeLaunchers` пропускает вход без команды, если есть `cwd`; битые `cwd`/`image` отбрасывает.
- Окно входа: поле «Папка» (путь + «Выбрать…» / сброс), команда без обязательности
  (сохранить можно, если есть команда или папка). Имя по умолчанию без команды — имя папки.
- Ряд значков: первая плитка «Своя картинка…» — диалог выбора картинки, Rust-команда
  `launcher_icon(path)` возвращает миниатюру 64×64 (переиспользует код миниатюр вложений).
  Выбранная картинка показывается в окне и в полосе вместо значка.
- `openLauncher`: новая вкладка открывается в `l.cwd` (иначе — как сейчас, в папке текущей);
  пустая команда — ничего не ставится в очередь. Повторный клик по открытому входу — только
  переключение (команды нет — повторять нечего).

## На усмотрение исполнителя
- Вид плитки «Своя картинка…», лимиты размера исходника, тексты подсказок.
