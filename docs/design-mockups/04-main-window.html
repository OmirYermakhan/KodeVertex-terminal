Агенты снизу

  • Перейти в список агентов⌘ ↓
  • Выбрать агента↑ ↓
  • Раскрыть подробности↵
  • Вернуться к вводуesc
  • Скрыть / показать⌘ J

Блоки (как Warp)

  • Выбрать блок выше / ниже⌘ ↑ / ↓
  • Скопировать вывод блока⌘ ⇧ C
  • Найти в выводе⌘ F
  • История команд⌃ R
  • Палитра команд⌘ P

Окна

  • Разделить вправо⌘ D
  • Разделить вниз⌘ ⇧ D
  • Новая вкладка⌘ T
  • Между панелями⌥ ⌘ ←→
  • Закрыть панель⌘ W
