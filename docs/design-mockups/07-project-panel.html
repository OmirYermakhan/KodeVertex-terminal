Как открывается

  • Кнопка «shop-app · ветка» слева вверху⌘1
  • Значки на полосе слеваклик
  • Повторный клик / escскрыть
  • Ширина панелитянуть край

Файлы

  • Открыть файл справа↵ / клик
  • Найти файл по именинабор в дереве
  • Показать текущий файл в дереве⌖
  • Во внешнем редакторе⌘↓

Только просмотр

  • Ничего не коммитит и не меняет
  • Обновляется сам, когда Claude правит файлы
  • Значок файла — в сообщение Claude⌘L
