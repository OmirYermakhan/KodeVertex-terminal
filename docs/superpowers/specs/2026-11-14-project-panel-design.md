# Панель проекта как в Android Studio

Макет (утверждён владельцем): `docs/design-mockups/07-project-panel.html` — три окна. Вёрстка и цвета —
точь-в-точь по макету (владелец требует совпадения с макетом).

## Зачем
Владелец работает с Claude в терминале и хочет, как в Android Studio, видеть весь проект слева, открывать
файлы и видеть, что поменялось: локально и в каждом коммите. Прежде всего — следить за тем, что трогает Claude.

## Цели
- Кнопка проекта слева вверху в строке вкладок: значок проекта (две буквы), имя, значок ветки и ветка, «▾».
  Клик или ⌘1 — показать/скрыть окно «Проект».
- Полоса инструментов слева (40px) со значками: Проект (⌘1), Изменения (⌘0), Git (⌘9). Активный — синяя
  плашка. Повторный клик / та же клавиша / esc (фокус в панели) — скрыть окно. Полоса видна всегда.
- Окно инструмента (290px по умолчанию, ширину тянуть за край, 200–600px, запоминается) — один из трёх видов:
  1. **Проект** — дерево файлов корня проекта. Папки раскрываются лениво. Цвет имени по git: изменён
     `--vcsMod #6c9fef`, добавлен (в индексе) `--vcsAdd #73bd79`, не отслеживается `--vcsNew #d1675a`,
     удалён — зачёркнут `--vcsDel`; папка с изменениями внутри — имя цветом «изменён». Удалённые файлы
     показываются в дереве на своём месте. Значки файлов — как в макете (K, X, G, M, ≡; цветные квадраты),
     папки — серые, `src/main/java` синяя, `res` жёлтая. Корень — жирное имя + серый путь `~/…`.
     Набор букв в дереве — переход к файлу по имени (как в AS speed search). ⌖ — показать открытый файл.
     `.git` не показывается.
  2. **Изменения** — группы «Изменения N файлов» (отслеживаемые: M/A/D/R) и «Не отслеживаются N файл»;
     строка: значок, имя цветом статуса, серый каталог, справа `+a −d` (или «новый»). Подвал:
     «+A −D · N файлов» и «Claude менял K из N» (файлы, которые Claude правил в текущей сессии этой вкладки).
  3. **Git** — первая строка «● Локальные изменения · N файлов» (клик → вид «Изменения»), ниже лог коммитов
     текущей ветки (по 100, догрузка при прокрутке): граф-точка, сообщение, метки веток/HEAD, короткий хэш,
     дата («сегодня 14:20», «вчера 19:05», «12 нояб.»). Клик по коммиту раскрывает его файлы (+a −d).
- Просмотр справа (только чтение):
  - **Файл** (из дерева): открывается справа от ленты (панели терминала сужаются), вкладки файлов как в AS
    (значок, имя цветом git-статуса, ✕, активная — синяя полоса снизу), строка: хлебные крошки,
    «🔒 только чтение», «Открыть в редакторе». Номера строк, подсветка (существующая `highlightLines`),
    на полях — полоски изменённых (`--vcsMod`) и добавленных (`--vcsAdd`) строк относительно HEAD.
    Клик по строке — текущая строка (фон); в строке состояния справа «Файл · строка:столбец · Язык · UTF-8».
  - **Изменения файла** (из «Изменения» или файла коммита): занимает всю область справа от окна инструмента
    (лента временно скрыта, как в макете окна 2–3); заголовок: путь, `+a −d`, плашка «HEAD → рабочая копия» /
    «новый файл в a41c9e2», кнопка «Открыть файл» / «Копировать хэш»; строки «было/стало» — как DiffView.
    Закрыть вкладку (✕ / ⌘W при фокусе на просмотре) — лента возвращается.
- Строка состояния: при открытой панели — «N изменено · M новый» (окно 1–2) или «хэш · N файла · +a −d» (Git).
- Обновление само: после каждого действия Claude, меняющего файлы (Edit/Write/MultiEdit/Bash завершились),
  после завершения команды в оболочке, при фокусе окна; не чаще раза в 500 мс. Открытый файл перечитывается.

## Не цели
Редактирование, коммит/пуш/откат, stage, ветки, blame, поиск по содержимому, сравнение двух коммитов.

## Анти-цели
- Тормоза: дерево на большом репо (node_modules, target) не должно читать всё сразу; git — с таймаутом.
- Безопасность: файлы читаются только внутри корня проекта; git запускается с той же защитой, что `git.rs`
  (GIT_ENV, GIT_SAFE_CONFIG, без хуков/fsmonitor, stdin закрыт, таймаут).
- Ломать текущее: вкладки, разделение панелей, ⌘W для панелей, xterm-ширина при сужении — работают как раньше.

## Ограничения
- Корень проекта — `git rev-parse --show-toplevel` от cwd панели в фокусе; не git — сам cwd. Смена вкладки/
  панели в фокусе — панель показывает её проект.
- Файл больше 2 МБ или 20 000 строк — показывается начало и строка «Файл большой — показаны первые N строк ·
  Открыть в редакторе». Бинарный — «Бинарный файл · размер · Открыть в редакторе».
- Дерево: папки `.git` скрыта; игнорируемые git (`git check-ignore`-статус из `status --ignored=matching`
  не используем) — показываются обычным серым; папка с >2000 записей — первые 2000 + «ещё N».

## Подходы
- **A (выбран): окно-уровень.** Полоса и окно инструмента — слева от `.panes` в App, просмотр — справа от
  `.panes`; данные — новые Rust-команды (`project.rs`), состояние — zustand-стор `src/project/`.
- B: панель внутри каждой TerminalPane — дублирование на каждую панель, конфликт со split. Отклонён.
- C: отдельное окно Tauri — сложнее, не как в AS. Отклонён.

## Решения владельца
Только просмотр. Вид — по макету 07. Открытие — кнопка слева вверху и полоса значков слева.

## Решения исполнителя (мои, владелец может поправить)
Горячие клавиши ⌘1/⌘0/⌘9 (как в AS); ширина окна запоминается в localStorage; изменения файла — во всю
ширину, обычный файл — рядом с лентой; «Claude менял» — по карточкам действий текущей Claude-сессии.
