## Что такое git rebase

Rebase переносит ваши коммиты на
новую основу — как будто вы начали
работу позже, с актуальной версии.

Как это работает:
1. git откладывает ваши коммиты
2. перематывает ветку на main
3. применяет коммиты заново

git checkout feature
git rebase main

Итог: история ровная, без лишних
merge-коммитов.
