# Схемы картинкой — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Блоки ```mermaid в ответах Claude показываются картинкой; Claude получает короткую подсказку рисовать схемы mermaid вместо ASCII.

**Architecture:** Флаг `--append-system-prompt` при запуске `claude` (Rust `Launch`), управляемый настройкой `claudeDiagrams`. На фронте — модуль `src/claude/diagram/` (ленивый `import('mermaid')`, строгий режим, SVG → `blob:` URL → `<img>`, кэш), подключённый в `Markdown` через `components.code`/`pre`. В `DiffView` для `.md` — переключатель «Как документ».

**Tech Stack:** Tauri 2 (Rust), React 19 + TS, react-markdown 10, mermaid 12 (npm, в бандле), vitest + jsdom, cargo test.

**Spec:** `docs/superpowers/specs/2026-11-14-diagrams-design.md`

## Global Constraints
- Сборка cargo/tauri: префикс `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.
- Весь текст интерфейса — по-русски. Комментарии в коде — по-русски, как в проекте.
- mermaid: `securityLevel: 'strict'`, `startOnLoad: false`, `htmlLabels: false` (и `flowchart.htmlLabels: false`); показ только через `<img src="blob:…">`, никогда `dangerouslySetInnerHTML`.
- Никаких сетевых запросов; mermaid грузится только `import()` при первой схеме.
- Настройка `claudeDiagrams: boolean`, по умолчанию `true`. Выключена — нет флага подсказки и нет отрисовки (блок — обычный код).
- Коммиты без упоминания ИИ и без строк Co-Authored-By.

## Review Focus
- Ответ ещё печатается, блок mermaid не закрыт → показывается код с подписью «Схема рисуется…», mermaid не вызывается (тест в Task 2).
- Ошибочный синтаксис → исходник + «Схему не удалось нарисовать», карточка не падает (тест в Task 2).
- Смена темы → схема перерисовывается в цветах новой темы (ключ кэша включает тему; тест в Task 2).
- Подпись со «<script>»/«onclick» в исходнике → в DOM нет `<svg>`/`<script>`, только `<img>` (тест в Task 2).
- Очень широкая схема → не шире карточки, прокрутка по горизонтали (CSS `.dg` `max-width:100%; overflow-x:auto`; проверка глазами в Task 4).

### Task 2: Отрисовка mermaid в Markdown

**Files:**
- Create: `src/claude/diagram/render.ts`, `src/claude/diagram/Diagram.tsx`, `src/claude/diagram/diagram.test.tsx`
- Modify: `src/claude/Markdown.tsx`, `src/global.css`, `package.json` (`npm i mermaid@12`)

**Interfaces:**
- Consumes: `Settings.claudeDiagrams`, `Settings.theme`, `THEMES` (`src/theme/themes.ts`).
- Produces:
  - `renderDiagram(src: string, themeId: ThemeId): Promise<{ ok: true; url: string } | { ok: false; error: string }>` — ленивый `import('mermaid')`, `initialize` при смене темы (themeVariables из `THEMES[id].tokens`: background=bg, primaryColor=panel2, primaryTextColor=text, primaryBorderColor=rule, lineColor=muted, secondaryColor=panel, tertiaryColor=bg, fontFamily системный sans), `mermaid.render(uniqueId, src)` → `URL.createObjectURL(new Blob([svg], {type:'image/svg+xml'}))`; кэш `Map` по `${themeId}\n${src}` (до 100 записей, старые — `revokeObjectURL`). Все вызовы mermaid — последовательно (очередь), mermaid не реентерабелен.
  - `<Diagram source={string} />` — `<div className="dg">`: `<img alt="Схема" src=url>`; кнопки «Исходник» (показывает/прячет `<pre>` с кодом) и «Копировать» (как `.md-copy`). Пока рендерится — код и подпись «Схема рисуется…». Ошибка — код + «Схему не удалось нарисовать».
  - `Markdown` получает проп `diagrams?: boolean` (по умолчанию из настроек `claudeDiagrams`); при `diagrams && !streaming` блок `pre > code.language-mermaid` заменяется `<Diagram>`; при `streaming` — обычный код с подписью «Схема рисуется…».
