# Вкладки в отдельных окнах (как в Warp)

Дата: 2026-11-17. Решение владельца: **живой перенос** (оболочка, запущенная команда, Claude
продолжают работать без перезапуска) и **склейка окон** (вкладку можно бросить в другое окно).

## Что видит пользователь

1. Вкладку на полосе можно тащить мышью.
   - Внутри полосы — меняет порядок вкладок.
   - Утащили за пределы окна (или ниже полосы больше чем на 40px) и отпустили не над другим окном —
     вкладка уезжает в **новое окно**, его полоса вкладок оказывается под курсором.
   - Отпустили над полосой вкладок (или любой частью) **другого окна приложения** — вкладка
     переезжает туда и становится активной, окно-приёмник получает фокус.
   - Окно, у которого забрали последнюю вкладку, закрывается (а не создаёт пустую вкладку).
     Единственную вкладку единственного окна вынести в новое окно нельзя (нечего отделять) —
     жест ничего не делает.
   - Во время перетаскивания вкладка полупрозрачна, за курсором — «призрак» с её названием.
2. ⌘N и пункт меню «Новое окно» — новое окно с одной новой вкладкой.
3. Перенос живой: работающая команда (ssh, vim, сервер, `npm run dev`) и процесс Claude
   (в том числе посреди ответа) продолжают работу. Лента, карточки Claude, очередь сообщений,
   раскладка панелей (сплиты), каталоги — переезжают целиком. Экран живого xterm (vim/htop/вывод
   текущей команды) переносится через `SerializeAddon.serialize()`.
4. Закрытие окна (красная кнопка) при других открытых окнах — закрывает его вкладки (процессы
   завершаются, как при ⌘W). Закрытие последнего окна — выход с сохранением, как сейчас.
5. Перезапуск приложения восстанавливает все окна с их вкладками.

## Бэкенд (Rust)

### Владелец процессов
Сейчас `on_page_load(Started)` убивает **все** PTY и claude — с несколькими окнами открытие
нового окна убило бы терминалы старого. Теперь у каждой сессии PTY и claude есть владелец —
метка окна (`Option<String>`), взятая из `tauri::WebviewWindow`/`Window` вызывающей команды.
- `on_page_load(Started)` окна L — убить только сессии владельца L.
- `WindowEvent::Destroyed` окна L — убить сессии владельца L, забыть его часть сессии и init.
- `kill_all`/`stop_all` на `RunEvent::Exit` — как сейчас.

### Переподключение (detach / attach)
Колбэки вывода (`on_data`/`on_exit`, `on_line`/`on_exit`) становятся заменяемыми (sink под замком).
- `pty_detach(id)`: пауза чтения (gate), sink снят, владелец = None. Вывод копится в ядре
  (программа упрётся в буфер — нормально, перенос < 1 с). Выход оболочки во время detach —
  код запоминается.
- `pty_attach(id, on_data, on_exit)`: владелец = окно вызова, новый sink, снять паузу; если
  оболочка уже вышла — сразу `on_exit(code)`. Неизвестный id — `Err`.
- `claude_detach(id)`: строки stdout копятся в очереди (не теряются, процесс не блокируется),
  владелец = None; выход запоминается (code, stderr).
- `claude_attach(id, on_line, on_exit)`: владелец = окно вызова, сначала отдать накопленные строки
  по порядку, потом живые; отложенный выход — после строк.
- Отсоединённая сессия, не подключённая за 30 с, — убивается (страховка от потерянного переноса).
- `pty_spawn`/`claude_start` — сигнатуры для фронта не меняются (окно берётся из вызова).

### Окна
- `window_open(payload: Option<Value>, x: Option<f64>, y: Option<f64>) -> String` — окно с меткой
  `w-<uuid>`, теми же параметрами, что `main` в tauri.conf.json (Overlay, hiddenTitle, minSize,
  размер — как у окна-источника, если есть, иначе 1280×800). `x,y` — экранные логические координаты
  курсора: левый верхний угол окна = (x − 120, y − 18), чтобы полоса вкладок была под курсором.
  `payload` хранится под меткой окна до `window_take_init`. Светофор (`traffic_lights::apply`)
  применяется и к новым окнам. Новое окно получает фокус.
- `window_take_init() -> Option<Value>` — забрать (один раз) payload своего окна.
- `window_send_tab(target: String, payload: Value)` — `emit_to(target, "tab://receive", payload)`
  и фокус окну target.
- `window_at(x: f64, y: f64) -> Option<String>` — метка другого (не вызывающего) видимого окна
  приложения, чей внешний прямоугольник содержит экранную логическую точку.
- `window_count() -> usize`.
- Меню: «Новое окно» ⌘N (Файл/приложение) → `window_open(None)`.
- capabilities: `"windows": ["main", "w-*"]`, плюс `core:window:allow-close`, `allow-set-focus`,
  `allow-outer-position`, `allow-inner-size` (что потребуется фронту).

### Сохранение сессии нескольких окон
Формат `session.json` остаётся версии 1 (старые сборки читают верхний уровень как раньше), плюс
необязательное поле `windows: SavedSession[]` — остальные окна.
- `session_save(text)` — часть окна-вызывателя; Rust держит `label → Value` в порядке открытия
  окон и пишет файл: верхний уровень = часть самого старого живого окна, `windows` = остальные.
- `session_load()` — только для `main` (первого окна): отдаёт верхний уровень; при первом вызове
  открывает по окну на каждый элемент `windows` с payload `{kind:'restore', session}`.
  Другие окна получают своё через `window_take_init`.
- Окно закрыли (Destroyed) при других живых — его часть удаляется и файл переписывается.
- Выход (⌘Q): `app://before-exit` всем окнам; `ExitFlow` ждёт `app_exit_ready` от **каждого**
  окна (счётчик = число окон в начале выхода) или таймаут.

## Фронт

### Payload нового окна / приёма
```ts
type WindowInit =
  | { kind: 'transfer'; tab: TabTransfer }
  | { kind: 'restore'; session: SavedSession }
  | null // пустое окно: одна новая вкладка

interface TabTransfer {
  tab: Tab // как в tabsStore
  panes: Record<string, {
    saved: SavedPane // как в persist/session (лента, claudeFrom, claudeMode, claude)
    live?: LivePane  // живой PTY панели
    claudeProcId?: string // живой процесс claude
  }>
}
interface LivePane {
  ptyId: string; mark: string; localHost: string | null; cwd: string | null
  running: boolean; raw: boolean; promptSeen: boolean
  xterm: string // SerializeAddon.serialize() — экран и scrollback живого xterm
  // + всё, что TerminalPane держит в ref-ах и без чего блок/ввод сломаются
}
```

### Отдача вкладки (`src/windows/transfer.ts`)
1. Для каждой панели вкладки: снимок `SavedPane` (переиспользовать `snapshot` из persist/session
   для одной вкладки), живое состояние у TerminalPane (реестр как `setPaneFeed`), `pty_detach`,
   `claude_detach` (если процесс есть; запуск в процессе — дождаться `proc.ready`).
2. Пометить панели «переезжают»: размонтирование TerminalPane/sessionStore не убивает PTY и claude.
3. Удалить вкладку из стора без автосоздания новой; если вкладок не осталось — закрыть окно.
4. `window_open({kind:'transfer', tab}, x, y)` или `window_send_tab(target, {kind:'transfer', tab})`.

### Приём
- Новое окно: `main.tsx` до первого рендера: метка ≠ `main` → `window_take_init`; transfer —
  вкладка единственная; restore — `applySession`; null — новая вкладка.
- Существующее окно: слушает `tab://receive` → добавляет вкладку, делает активной.
- TerminalPane панели с `live`: вместо `spawnPty` — пишет `xterm` в новый Terminal, восстанавливает
  ref-ы (mark, localHost, running, raw, promptSeen, cwd), затем `pty_attach` с новыми каналами
  (`attachPty` в ptyClient) и `resize` под новый размер.
- sessionStore: сессия Claude из `saved.claude` (как restore), но с живым `procId` —
  `claude_attach` с новыми каналами, без перезапуска.

### Сохранение
Каждое окно сохраняет свою часть (`session_save`) как сейчас. `restoreSession` в `main` — как
сейчас (Rust сам откроет остальные окна).

### Перетаскивание (TabBar)
Pointer events на `.tab` с `setPointerCapture` (macOS шлёт mouseDragged окну, получившему
mouseDown, даже за его пределами). Порог начала — 4px. Позиция курсора на экране —
`e.screenX/e.screenY`. На `pointerup`:
- внутри полосы — перестановка (`useTabs.move(from, to)`);
- иначе `window_at(screenX, screenY)` → есть окно → перенос туда; нет и курсор вне окна или ниже
  полосы на 40px+ → новое окно; иначе — отмена.
Клик без движения — как сейчас (активировать), средняя кнопка — закрыть.

## Вне рамок
- Перетаскивание отдельной панели (сплита) в другое окно.
- Вкладка-«призрак» в чужом окне во время перетаскивания (предпросмотр места вставки) —
  вставка в конец.

## Проверка
Rust-тесты: detach/attach PTY (вывод во время detach не теряется, выход во время detach
доставляется), claude detach/attach (строки по порядку), владелец (kill только своего окна),
сборка файла сессии из частей. Vitest: transfer (снимок вкладки, удаление без нового таба, приём),
TabBar (перестановка, вынос, порог). Ручная проверка владельцем в установленном приложении:
вынести вкладку с запущенным `ping`, с vim, с Claude посреди ответа; вернуть в другое окно;
⌘Q и перезапуск — окна восстановились.
